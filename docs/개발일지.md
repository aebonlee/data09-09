## 3. 결정과 이유

- **정적 웹 도구로 오프라인 요구를 충족**했습니다. 기획서가 「인터넷 없는 PC + 장비 연결 없는 분석 전용」을 요구했고, 파일로 여는 HTML 이 설치 없이 둘 다 만족합니다. Python 전용으로 갈 이유(폐쇄망에서 브라우저 금지 등)는 제출 자료에 없었습니다.
- **Channel Mapping 은 09:30 판을 글자 그대로 따랐습니다.** 자동추천 결과는 「확인」이 체크되지 않은 제안이고, 헤더·단위·역할을 바꾸면 그 행의 확인과 Mapping Confirm 이 풀립니다. 압력 헤더에 단위 표기가 없으면 단위를 비워 두고 분석을 막습니다. 전압 채널(`[mV]`)은 단위가 맞지 않아 Arm Angle 후보에서 빠집니다.
- **「매핑된 행 모두 확인 표시」 버튼**을 두었습니다. 행마다 체크하는 번거로움을 줄이려는 것이고, 누르는 것 자체가 사용자의 확인입니다. 필수 단위·역할이 비어 있으면 이 버튼을 눌러도 Confirm 은 막힙니다.
- **UP/DOWN 분리 모드에서 이벤트 방향에 맞는 채널**로 Ramp 를 잽니다(방향은 Arm Angle 미분). 한 방향에 채널이 둘이면 Command 역할을 먼저 씁니다. 단일 모드는 부호 규칙이 확인되지 않아 전류 크기(절댓값)로 잽니다(가정).
- **전류 % 보정이 없으면 mA/s 로 비교하고 추천을 막습니다.** 막는 조건은 「지금 보고 있는 로그의 매핑에 보정이 없을 때」입니다. 로그 없이 라벨만 있을 때는 추천을 보여 줍니다(추천은 라벨의 설정값 %/s 기준이라 로그 단위와 무관).
- **결측은 0 으로 채우지 않습니다.** 허용 길이(기본 3행, 가정) 이하만 앞 값으로 잇고, 넘는 구간·시간 역전·Sampling 공백은 표시해 두었다가 그 구간이 분석 Window 에 들면 이벤트를 NO DATA 로 둡니다. 미분은 실제 시간값으로 계산합니다(10 ms 고정 가정 없음).
- **판정표는 제출자 스케치대로 「안정도(ΔPitch) · 충격지수 · 응답성 · 종합판정」 네 줄**입니다. 안정도는 범위, 충격지수·응답성은 상한입니다. 스케치의 숫자는 기준으로 쓰지 않았습니다.
- **Shock Index 는 가정 식**(가중치 × max|dP/dt|/기준 + 가중치 × max|d²Pitch/dt²|/기준)이며 기준·가중치를 설정 화면에서 바꿉니다. 원시 Feature 도 모두 함께 보입니다.
- **추천은 Rule 기반**입니다. 해당 파라미터의 Accepted 라벨 ramp 값 중 상위 백분위(기본 75%, 가정)를 목표로, 한 번에 현재값의 ±20%(가정)까지만 움직이고 Min/Max·Step 안에서 냅니다. 「충격 최소가 아니라 허용범위 안 최적 응답성」이라는 기획서 방향을 따라, 느린 쪽이 아니라 허용된 값 중 빠른 쪽을 향하게 했습니다. Accepted 가 최소 건수(기본 3건) 미만이면 임의값을 만들지 않고 「추천 불가/데이터 부족」입니다.
- **ECU 값은 「기울기 × 배율」 하나로 환산**합니다(기본 배율 1). 실제 환산식이 오면 로직 한 곳만 바꾸면 됩니다.
- **Ramp 그래프는 개념 Profile**(0 → 목표 Current 를 Start 기울기로, 유지, Stop 기울기로 0)입니다. ECU 내부 Profile 계산식이 확인되지 않았기 때문입니다(기획서 10장).
- **Safety Limit 은 기본으로 꺼 두었습니다**(값이 없음). 넣으면 감성 기준보다 먼저 적용되고, 초과 이벤트가 있는 로그를 보는 중에는 최종 Confirm 을 막습니다.
- **로그 원본은 브라우저에 저장하지 않습니다**(용량). 확정한 매핑은 Mapping Profile 로 저장해 다음 파일에서 되살립니다.
- 화면을 옮길 때 맨 위로 스크롤하게 했습니다. 스모크에서 이벤트 표(아래쪽)를 누르고 넘어가면 Calibration 화면이 중간부터 보이던 것을 잡았습니다.

## 4. 가정 (실제 자료로 바꿀 것)

- 파라미터 범위 10~1000 %/s, Step 1, ECU 배율 1, 인접 Zone 차이 경고 50%
- 정확히 30/50/70% 는 위쪽 Zone
- 검출: 이동평균 5점, Start 3 %/s, Stop 1.5 %/s, Hold 0.05 s, Window −1.0/+1.5 s, Current 시작 판정 변화폭의 5%
- Shock Index 기준값 dP/dt 400 bar/s, d²Pitch/dt² 60 deg/s², 가중치 0.5/0.5, CAUTION 폭 10%
- 결측 이어 계산 최대 3행, Sampling 공백 = Δt 중앙값 × 5
- 예시 데이터: 로그 값·라벨·예시 채널맵의 역할(Command)·압력 단위(bar)·보정값(100 mA=0%, 650 mA=100%)은 모두 합성 데이터에 맞춘 값입니다. 예시 Set 의 UP 값은 제출자 스케치 숫자를 옮긴 것이고 DOWN 은 임의값입니다.
